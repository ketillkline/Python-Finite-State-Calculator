# Python-Finite-State-Calculator
Calculator written in python that can perform basic operations. Uses distinct states to keep track of input progression and user actions. 

## The Story Behind This Project
Well, here I am. This is my second official Python Project to be posted to GitHub. It was a hard one, truthfully, and there are a lot of things I'd like to change about it. The coding is fragile, mostly. But it's been almost two weeks, and I feel confident enough to post it here. 
My first, unofficial Python project was actually another calculator, basic as it was. After creating my Monster Battle Simulator, I wanted to expand on the idea of a calculator using my newly learned GUI capabilities thanks to TKinter.
This project taught be about FSMs. Before, I had no idea what they were, and discovered them through pure trial-and-error on my own. I wanted to make not just something functional, but pretty, both on the inside and out. The button layout in particular impressed me, as it looked exactly like the calculator I have on my phone!
With all that being said, this calculator is functional and it was a fun project to build. I learned more about OOP and discovered FSMs, Tuples, and used try, except for the first time!

## Project Aim
The purpose of this project is to allow the user to perform basic operations. Chained equations are possible, as well as a Calculation History to record all previous equations for future reference. It was designed to be easy to use with just a mouse.

## Features
1. A delete button to delete digits
2. A clear button to completely reset the calculator
3. Decimal points to expand breadth of calculation
4. Calculation History to view all previous equations
